A byte order mark decides first, then the charset label, as from an HTTP Content-Type header. For HTML, then the encoding a <meta> declares, and for XML the XML declaration; XML is never guessed. Otherwise the detector, a port of chardetng, guesses, using the top-level domain the file came from as a hint.

Scores

How plausible the bytes are in each encoding the detector considers, higher being more plausible, without the top-level domain hint. Choose an encoding to decode the file with it.

    Decoding refuses a byte sequence that is not valid in the encoding instead of replacing it with U+FFFD, and shows where it is. A wrong guess can still decode without error, to the wrong letters.
